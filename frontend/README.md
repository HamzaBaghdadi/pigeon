# Pigeon frontend

The Pigeon UI: Next.js (App Router) built as a **static export** into `dist/`,
which Wails embeds into the Go binary. There is no Node server at runtime.

- `src/components/`: the mail UI (sidebar, list, reader, dialogs)
- `src/lib/api.ts`: typed wrapper over the Go services
- `bindings/`: generated by `wails3 generate bindings` (don't edit by hand)

Run the whole app from the repository root with `wails3 dev`. To check the
frontend on its own:

```bash
npm run typecheck
npm run lint
npm run build
```
